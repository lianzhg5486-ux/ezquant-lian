# 2026-11-21 项目变更记录

## 本次更新：接入蛋卷基金指数估值数据

### 1. 新增指数估值数据模块

新增 `ezquant/valuation.py`，接入蛋卷基金公开估值接口：

`https://danjuanfunds.com/djapi/index_eva/dj`

支持获取以下指数估值数据：

- PE：市盈率
- PB：市净率
- PE_percentile：PE 历史百分位
- PB_percentile：PB 历史百分位
- ROE：净资产收益率
- dividend_yield：股息率
- valuation_status：估值状态
- valuation_date：估值日期

目前已成功获取蛋卷估值中心的 63 个指数数据。

### 2. 新增指数名称与代码映射

支持项目指数名称、蛋卷指数名称及不同格式指数代码之间的匹配。

支持的示例：

- 沪深300指数 / 沪深300 / 000300 / SH000300
- 证券公司指数 / 证券公司 / 399975 / SZ399975
- 创业板指 / 创业板 / 399006 / SZ399006
- 中证海外中国互联网50 / 中概互联50 / H30533 / CSIH30533

### 3. 新增 ETF 指数估值查询

新增 `get_etf_valuation()`。

支持通过 ETF 名称或代码，自动关联其跟踪指数并获取蛋卷估值数据。

当前项目 ETF 映射：

| ETF | 代码 | 跟踪指数 |
|---|---|---|
| 证券ETF | 512880 | 证券公司指数 |
| 中概互联网ETF | 513050 | 中证海外中国互联网50 |
| 沪深300ETF | 510300 | 沪深300指数 |
| 创业板ETF | 159915 | 创业板指 |

### 4. 完善统一接口

修改 `ezquant/__init__.py`，统一导出估值模块接口：

- `get_all_index_valuations()`
- `get_index_valuation()`
- `list_valuation_indices()`
- `get_etf_valuation()`

### 5. 数据源职责划分

- AkShare：负责 ETF 和指数历史行情数据。
- 蛋卷基金：负责指数当前估值快照。

当前估值数据与历史行情数据保持独立，不将当前估值回填至历史日期，避免回测产生未来数据泄漏。
